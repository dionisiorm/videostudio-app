Política de privacidad

Video Studio · actualizada el 22 de noviembre de 2026

Qué es Video Studio

Video Studio es una aplicación de escritorio privada que se ejecuta solo en la computadora de su dueño. No tiene servidores propios ni cuentas de usuario.

Qué datos de Google usa

Cuando el usuario conecta un canal, la aplicación pide a Google dos permisos de solo lectura:

  • YouTube Data API (youtube.readonly): el nombre del canal y la lista de sus videos (título, fecha, duración y número de vistas).
  • YouTube Analytics API (yt-analytics.readonly): las estadísticas de esos videos (impresiones, porcentaje de clics, vistas, tiempo de visualización, retención y suscriptores ganados).

La aplicación no sube, cambia ni borra nada en YouTube ni en la cuenta de Google.

Para qué los usa

Solo para mostrarle al propio usuario cómo funcionan sus videos y ayudarle a decidir los próximos temas, títulos y miniaturas.

Dónde se guardan y con quién se comparten

  • El permiso de Google y las estadísticas se guardan solo en la computadora del usuario.
  • No se venden, no se usan para publicidad y no se comparten con terceros.
  • Para preparar sugerencias, la aplicación puede incluir un resumen de esas cifras en las peticiones que el propio usuario hace a su asistente de IA (Claude, de Anthropic). Ese envío lo inicia el usuario desde su propia cuenta.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el permiso

El usuario puede desconectar cada canal dentro de la aplicación, o retirar el permiso cuando quiera en myaccount.google.com/permissions. Al hacerlo, la aplicación deja de recibir datos.

Privacy policy (English)

Video Studio is a private desktop app that runs only on its owner's computer, with no servers or user accounts of its own. When a channel is connected, it requests read-only access to the YouTube Data API (youtube.readonly: channel name and video list) and the YouTube Analytics API (yt-analytics.readonly: impressions, click-through rate, views, watch time, retention and subscribers gained). It never uploads, edits or deletes anything.

The data is used only to show the user how their own videos perform. The access token and statistics are stored only on the user's computer. They are not sold, not used for advertising and not shared with third parties; a summary may be included in requests the user makes to their own AI assistant (Claude by Anthropic). Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time in the app or at myaccount.google.com/permissions. Questions: open an issue in this page's repository.
